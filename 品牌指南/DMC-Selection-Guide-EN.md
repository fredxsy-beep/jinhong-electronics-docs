DMC (Daniels Manufacturing Corporation) is a US manufacturer of connector tools. Its crimp tools are designed to the MIL-DTL-22520 / AS22520 specification system and cover the full crimping, insertion/removal and inspection workflow for aerospace and industrial-electronics wire harnesses — the standard tooling system for high-reliability harness manufacturing. ## Product Lines Overview

The DMC tool system has five lines. First, **8-indent hand crimp tools**, which use a positioner to fix the contact in place and a ratchet cycle-control mechanism to guarantee that every crimp stroke runs to completion — the jaws do not release until the stroke is finished, eliminating by mechanical design the "half crimp" defect that cannot be seen on the surface yet can halve the pull strength. Second, **pneumatic crimp tools**, in the same system and using the same positioners as the hand tools, for upgrading to high-takt production lines. Third, **formed crimp tools (HX series)**, which use interchangeable dies to suit many contact and terminal lug types. Fourth, **contact insertion/removal tools, shield termination tools and safety-cable tools**. Fifth, the **Alphatron pull tester**, which turns crimp quality from a matter of feel into measured data. One crimp tool, one matching positioner and one pull tester form a complete crimp-quality closed loop.

## Selection Guide

1. **Divide the work by wire size first — do not use a tool outside its range.** Use the AFM8 for miniature contacts (AWG 32–20), the MH860 for small-to-medium sizes (AWG 32–16) and the AF8 for the mainstay range (AWG 26–12); for AWG 10 and larger, or where contact types are mixed and include terminal lugs, switch to HX4 formed crimping. The AF8 limit is AWG 12 — crimping beyond its range will inevitably produce a non-conforming crimp.
2. **Positioners, dies and tool bodies are separate systems of their own.** The AFM8 uses K-series positioners, the AF8 uses TH / TP types and the MH860 uses the 86 series — none can be borrowed across tools; likewise the Y dies of the HX4 and the X dies of the HX3 cannot be mixed. The selection order should be: list the contacts first, then fix the positioner or die, and only then fix the tool body.
3. **Prefer tools with ratchet cycle control.** Cycle control guarantees a complete stroke and consistent indents on every crimp; it is the key mechanism that moves quality control forward to the tool itself. Tools without cycle control easily let half crimps pass into the next process step.
4. **Establish the standard before volume production.** After changing a contact–wire combination, first verify the crimp-depth setting with the calibration gage, then run pull-to-fail tests on the MPT-250C to set the internal minimum pull strength; in production, run Force Hold sampling by batch and keep records. If sampling fails, check the positioner and the depth setting first, then the contact batch, and only then the operator technique.
5. **Match insertion/removal tools to the connector.** The suffix must be selected by connector family and contact size; tools for front-release and rear-release connectors are not interchangeable. Using tweezers or other substitutes to push contacts easily bends pins and damages the locking structure.
6. **The upgrade path is smooth.** When a manual workstation cannot keep up with the takt time, upgrade within the same system to the pneumatic equivalent (AFM8 → WA22, AF8 → WA27F, MH860 → WA22P); existing positioners and process parameters carry over, with no need to re-establish the standard.

## FAQ

**Q: What is the difference between the AF8 and the HX4 — if I buy only one, which should it be?**
A: The AF8 is an 8-indent crimp tool that uses positioners to suit circular-connector contacts and gives high crimp consistency; the HX4 is a formed crimp tool that uses interchangeable dies to suit many contact and terminal lug shapes. If contacts are mainly circular-connector contacts, choose the AF8; if types are mixed and include terminal lugs, choose the HX4 — the two are complementary. If buying only one, look also at the dominant wire size: if AWG 26–12 makes up the majority, buy the AF8 first; if miniature contacts dominate, buy the AFM8 first.

**Q: The crimp is finished — why test the pull strength as well?**
A: A crimp that looks acceptable does not necessarily pass on pull strength — a misaligned positioner or an off depth setting can halve the pull strength with no visible difference. Pull-to-fail calibration plus Force Hold sampling with a pull tester is the only way to catch this kind of hidden defect before shipment.

**Q: Where is Safe-T-Cable better than traditional lockwire?**
A: It replaces the lockwire process with prefabricated cable assemblies: installation is faster, tension is consistent and controllable, there is no broken-wire foreign-object (FOD) risk, and repetitive strain on the operator is reduced. Traditional lockwire quality depends heavily on operator technique, so batch consistency is poor.
