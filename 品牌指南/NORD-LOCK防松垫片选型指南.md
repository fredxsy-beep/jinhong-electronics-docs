# 四川省金宏电子 防松垫片 NORD-LOCK 选型指南

Nord-Lock（瑞典 Nord-Lock Group）是楔形防松技术的原创发明者。其垫片由一对成对垫片组成：一面是凸轮面、另一面是径向锯齿面，拧紧时锯齿嵌入配合面；当螺栓受振动趋于松动时，凸轮面之间的楔形效应（凸轮升角大于螺纹升角）会把连接越锁越紧——用机械锁紧替代靠摩擦的传统防松，并通过 Junker 振动试验验证。四川省金宏电子有限公司经销 Nord-Lock 楔形防松垫片，可按螺栓规格、材质环境与工况协助对位选型。Nord-Lock Group 旗下另有 Superbolt 机械式拉伸器、Boltight 液压拉伸器、Expander 膨胀销系统三大技术品牌。

## 产品线总览

楔形防松垫片按"材质环境×功能"分五条线：一是**原装钢制 NL / NLsp**，锌片涂层，为通用工况的标准库存线，sp 为加大型（外径加大，配合大孔、长孔或软质法兰面）；二是**不锈钢 NLss / NLspss**，常用材质 EN 1.4404，面向潮湿与一般腐蚀环境；三是 **254 SMO 高耐蚀线 NLss-254 / NLspss-254**，面向含氯等强腐蚀环境；四是**钢结构专用 NLSC**，面向建筑钢结构连接；五是 **X 系列 NLX / NLXsp**，在楔形防松之外叠加弹性效应补偿沉降与松弛造成的预紧力损失，适用于涂装表面、软材料、多层夹持与短夹持长度等普通垫片容易"压塌失紧"的设计。安装无需专用工具，垫片成对使用、不可拆对混装。

## 选型要点

1. **先按螺栓规格定尺寸**：垫片型号数字对应螺栓公称直径（NL12 对 M12、NL8 对 M8），一对一成对使用。被连接件有大孔、长孔或配合面较软时选 sp 加大型，用更大的外径分散面压、防止压陷。
2. **材质按腐蚀环境分级**：干燥室内工况用钢制 NL；潮湿与一般户外用不锈钢 NLss（EN 1.4404）；含氯化物（如海洋、化工）环境升级到 254 SMO 线。材质选低了，垫片先于螺栓锈蚀失效。
3. **有沉降/松弛风险直接选 X 系列**：涂装或粉末涂层表面、铜铝等软材料、垫片接头、短夹持长度、多层夹持——这些设计在拧紧后会发生沉降，普通垫片随之丢预紧力；X 系列的锥形弹性结构能补偿这部分损失，同时保留楔形防松。
4. **注意 X 系列的不适用情形**：配合面未锁定、配合面硬度高于垫片、木材/塑料等极软配合面，不推荐使用 X 系列，应回到原装 NL 系列或调整连接设计。
5. **关键部位按"防松失效后果"选型**：风电、轨道交通、重型机械、桥梁等高振动且失效后果严重的连接，优先楔形防松并保留 Junker 试验验证依据；普通静载连接不必过度配置。
6. **重复使用有条件**：垫片拆卸后检查凸轮面与锯齿面无损伤可重复使用，但关键安全部位建议更换新品；正品垫片有激光标记（含可追溯批次号与类型代码），无标记或标记模糊的不要用于关键连接。

## 常见问题

**问：NORD-LOCK 垫片和弹簧垫圈到底差在哪？**
答：弹簧垫圈靠弹力与摩擦防松，振动下摩擦副一旦发生横向滑动就快速失效；NORD-LOCK 靠楔形凸轮的几何锁紧——螺栓越想松动，凸轮面产生的楔紧力越大，与摩擦无关，并经 Junker 振动试验证明防松效果远超弹簧垫圈。高振动、关键部位应选楔形防松。

**问：NL 和 NLX（X 系列）怎么选？**
答：两者防松原理相同，差别在 X 系列多了沉降补偿：连接里有涂层、软材料、多层夹持、短夹持长度等会"压塌"的因素，选 NLX；配合面是干净金属对金属、夹持长度充足的标准连接，选 NL 即可，成本更低。

**问：怎么辨别 NORD-LOCK 正品？**
答：正品垫片加工精密、楔形面与锯齿面规整，X 系列带激光标记（可追溯批次号与类型代码）；建议从正规经销渠道采购，避免用外观仿冒品替代——防松件失效往往没有预警，关键连接不要赌在来路不明的垫片上。
