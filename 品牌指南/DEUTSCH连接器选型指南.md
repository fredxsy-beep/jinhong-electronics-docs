# 四川省金宏电子 密封式连接器 DEUTSCH 选型指南

DEUTSCH 是 TE Connectivity 旗下的密封式连接器品牌，产品以热塑性外壳加硅橡胶密封、端子压接式接线为共同特征，面向工程机械、商用车、农业机械与工业设备的线束连接，是恶劣环境电气连接的主流体系之一。四川省金宏电子有限公司经销 DEUTSCH 连接器产品，可按回路电流、腔数与安装环境协助成套选型，并配套供应压接与安拆工具。本文只作产品选型参考，具体料号以下单时核对为准。

## 产品线总览

DEUTSCH 密封连接器按端子规格（Size）分四个电流等级，构成清晰的选型阶梯：**DTM 系列**用 Size 20 端子，是低电流多芯的信号级产品；**DT 系列**用 Size 16 端子，是覆盖面最广的通用主力；**DTP 系列**用 Size 12 端子，承担较大功率回路；**DTHD 系列**是单路大电流产品，端子规格达 Size 4／8／12。此外还有 **HD30／HDP20 重载圆形系列**，属卡车与工程机械类重载圆形连接系统。各系列的共同结构是壳体＋对应 Size 的针／孔端子＋锁紧楔（wedge lock）＋线封的成套构成，密封靠硅橡胶线封与界面密封实现，选型逻辑是"先按电流定 Size 等级，再按腔数与安装方式定壳体，最后核对成套附件"。

## 选型要点

1. **先按电流定 Size 等级**：信号与小电流回路用 DTM（Size 20、7.5 A），常规动力回路用 DT（Size 16、每针 13 A），较大功率用 DTP（Size 12），单路大电流用 DTHD（Size 4／8／12）。等级定错，壳体、端子与工具要整套跟着换。
2. **密封等级与环境挂钩**：DT 系列本体达 IP67／IP68，带尾部防护（backshell）时可达 IP6K9K；户外、高压水冲洗或重粉尘环境必须配尾部防护并装好线封，只订裸壳体达不到标称防护等级。
3. **编号先解码再下单**：DT 系列料号中 06 为插头、04 为插座，S 为孔端子、P 为针端子。公母与针孔配反是 DEUTSCH 采购最常见的返工原因，下单前按编号规则逐项核对壳体、端子极性与腔数。
4. **按成套清单订货**：一套完整连接包括插头与插座壳体、对应 Size 的针／孔端子、锁紧楔与线封，冲洗环境再加尾部防护。只订壳体、漏订端子与锁紧楔，是到货后无法装配的典型疏漏。
5. **温度与振动按工况核对**：DT 系列工作温度 −55°C 至 +125°C，目录规格含耐久 100 次插拔与 21 Grms 至 2000 Hz 振动指标；发动机舱、高温或强振工位应按目录性能规格逐项核对，不要只凭系列名想当然。
6. **工具与端子配套**：DEUTSCH 端子为压接式接线，压接钳须按端子 Size 与线规选配，端子拆装用对应系列的退针／取送工具；用非配套工具压接，压接拉力与端子锁止都无法保证。金宏可配套供应 TE 压接与安拆工具。
7. **维修替换先核旧件编号**：替换在役线束的连接器时，先抄录旧件壳体编号与端子 Size，再按编号对位新件；DEUTSCH 各系列外形相近但端子体系不互通，仅凭外观判断系列是维修配错的高发原因，必要时提供旧件照片协助核对。

## 常见问题

**问：DT 和 DTM 怎么分工？**
答：两者是同一密封体系的不同电流等级：DTM 用 Size 20 端子、每针 7.5 A，体积小、多芯至 12 腔，适合信号与小电流回路；DT 用 Size 16 端子、每针 13 A，是通用主力。按回路电流选等级、按芯数选腔数即可；功率再大上 DTP，单路大电流用 DTHD。

**问：只买壳体可以吗，还需要配什么？**
答：不可以单独成套。壳体之外必须配对应 Size 的针／孔端子、锁紧楔与线封，户外或冲洗环境再加尾部防护。订货时提供连接器型号，金宏可协助核对成套清单，避免漏项返工。

**问：DT06 和 DT04 有什么区别？**
答：这是 DT 系列的编号规则：06 表示插头、04 表示插座，后缀 S 表示孔端子、P 表示针端子。看懂编号就能判断公母与针孔方向，选型对接时先把编号解码再核对清单，可以避免最常见的配错。高压水冲洗工况选型时同理先看防护构成：本体 IP67／IP68、加尾部防护后 IP6K9K，编号与防护两项都核对完再下单。
