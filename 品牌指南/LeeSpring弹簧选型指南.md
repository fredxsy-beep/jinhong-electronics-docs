# 四川省金宏电子 弹簧 Lee Spring 选型指南

Lee Spring 是弹簧产品品牌，产品线覆盖压缩弹簧、拉伸弹簧、扭转弹簧等标准规格弹簧与按图定制弹簧，服务于仪器仪表、电子设备、机械装置中的复位、缓冲、储能与力保持环节。四川省金宏电子有限公司经销 Lee Spring 弹簧产品。本文为产品线级选型指南：金宏在档素材未载 Lee Spring 的具体规格数值，具体型号的线径、外径、刚度等参数以下单时按厂家目录与图纸逐项核对为准，本文不补写无出处数值。

## 产品线总览

Lee Spring 产品线按受力方式分三大类：**压缩弹簧**承受轴向压力，是用量最大的一类，用于复位、压紧与缓冲；**拉伸弹簧**承受轴向拉力，靠初始张力与两端钩环传递拉力，用于回位与张紧机构；**扭转弹簧**靠簧臂受扭储能，用于铰链、夹持与回位转矩机构。在此之外是**按图定制**方向：标准目录规格覆盖不了的安装空间或刚度要求，按图纸参数定制。三类弹簧的受力方式、端部形式与失效模式完全不同，选型的第一步永远是先定类型，再谈尺寸。

## 主要产品线清单

| 产品线 | 规格／用途 |
|---|---|
| 压缩弹簧 | 轴向受压，用于复位、压紧、缓冲；规格按线径、外径、自由长度、圈数核对厂家目录 |
| 拉伸弹簧 | 轴向受拉，两端钩环连接，用于回位与张紧；规格按线径、外径、体长、钩型与初始张力核对 |
| 扭转弹簧 | 簧臂受扭输出转矩，用于铰链与夹持回位；规格按线径、内径、圈数、簧臂形式与扭转方向核对 |
| 定制弹簧 | 标准规格无对应时按图纸定制，输入为类型、尺寸、刚度/载荷要求与材料 |

## 选型要点

1. **先按受力方式定类型**：受压选压缩、受拉选拉伸、需要转矩选扭转。类型选错，后面尺寸再准也装不上、用不对，这是弹簧选型不可跳过的一步。
2. **四个基本量决定刚度**：线径、弹簧外径（或内径）、有效圈数、自由长度共同决定弹簧的刚度与行程。改其中任何一个，力值都会变；订货时四项连同材料一并给出，不要只报外径和长度。
3. **按工作位置校核力值**：选型看的是工作高度（或工作角度）下的力，不是自由状态参数。把安装位置与最大工作位置两个点位的力值都核对到机构要求内，再定规格。
4. **压缩弹簧不要压并使用**：压到并圈高度后刚度骤升、应力超限，弹簧会很快永久变形甚至断裂。设计行程要给并圈高度留余量，长期在接近并圈状态工作时应改选更长或更强的规格。
5. **材料按环境选**：一般环境用碳钢类，潮湿与腐蚀环境选不锈钢类，高温工况要核对材料的适用温度上限。材料选错的表现是刚度衰减与锈蚀断裂，都发生在装机之后，选型阶段就要排除。
6. **端部形式要写清**：拉伸弹簧的钩型、扭转弹簧的簧臂形状与方向，直接决定能否装配。订货描述中把端部形式单独写明，最好附机构接口的简图或照片。
7. **寿命按工作应力水平评估**：弹簧的疲劳寿命取决于工作应力相对材料极限的水平，长期在高应力区间往复的弹簧衰减明显快于轻载弹簧。选型时不要只满足静态力值，动作频繁的机构应把规格留一档余量，或在订货时把预期动作频次告知金宏协助核对。

## 常见问题

**问：弹簧选型要提供哪些参数？**
答：五类信息：弹簧类型（压、拉、扭）、安装空间（孔径或轴径、可用长度）、工作行程、工作位置的目标力值（或转矩）、使用环境（温度、腐蚀介质）。信息齐全后按厂家目录对位规格；只给外形尺寸定不了弹簧。

**问：原弹簧坏了，照原样买一支就行吗？**
答：可以按原样对位，但先确认原弹簧的失效原因：断裂多为超行程或腐蚀，变短（自由长度衰减）多为长期过载或温度过高。原因不排除，新弹簧会同样坏。把旧件的失效形态一并告知金宏，协助判断是否需要调整规格或材料。

**问：标准目录里找不到合适的规格怎么办？**
答：走定制：把安装空间、工作行程与目标力值给出，按图定制。若需求量小，也可以先复核相邻标准规格在机构侧微调安装尺寸的可行性，两条路的成本与周期由金宏核对后给出建议。
